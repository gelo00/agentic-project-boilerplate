# Task Preparation Workflow

When assigned a feature:
1. Create a task scratch folder: `knowledge/<feature-name>/` [4].
2. Add `trd.md` with acceptance criteria linked to `docs/srs/srs.md` [4].
3. Add `implementation-strategy.md` outlining contract changes, API endpoints, UI slices, and test plans [4].
4. Add `progress.md` containing a subtask checklist [4, 10].
5. Await user confirmation before writing code [4, 5].
